# Polar Ascent

A custom skin for Kodi 21 (Omega), based on **[Arctic Fuse 3](https://github.com/jurialmunkey/skin.arctic.fuse.3) by [jurialmunkey](https://github.com/jurialmunkey)**.

This repository is the Kodi add-on repository for Polar Ascent and the dependencies it needs.

## Credits

Polar Ascent is a modified version of Arctic Fuse 3. Nearly all of the skin's design, layout and code come from jurialmunkey's original work. Full credit to him.

If you enjoy the skin, please support the original developer: https://ko-fi.com/jurialmunkey

The dependency add-ons in this repository (TMDb Helper, Skin Variables, Texture Maker and others) are also the work of their original authors. Each is redistributed unchanged under its own license.

## What Polar Ascent changes

- Fixed the spotlight black-background bug (a zoom constant that was used but never defined)
- Local clearlogos take priority over TMDb Helper's cropped logos
- Fixed a PVR genre crash, the background image browser and spotlight loading on hub screens
- Added custom hub backgrounds and a "Check for Repository Updates" button
- Custom spotlight styling and highlight colors

## Installation

1. In Kodi, go to **Settings > System > Add-ons** and enable **Unknown sources**.
2. Download `repository.polar.ascent-1.0.0.zip` from the `repository.polar.ascent` folder in this repository.
3. In Kodi, go to **Add-ons > Install from zip file** and select the zip.
4. Go to **Install from repository > Polar Ascent Repository > Look and feel > Skin > Polar Ascent**.
